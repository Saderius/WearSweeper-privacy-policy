## 📖 About
This repository hosts the built-out landing page and privacy policy site for **WearSweeper**. We believe in strict transparency, and this site serves to outline our privacy commitments to our users.

WearSweeper brings the classic logic puzzle game to your wrist, optimized exclusively for WearOS smartwatches!

## ✨ Features
- **Privacy First:** Clearly defined layout focusing on user privacy—no tracking, no hidden data collection.
- **Fully Responsive:** Beautifully crafted with Tailwind CSS, fitting mobile, tablet, and desktop screens perfectly.
- **Modern Stack:** Built with Vite + React 18 + Motion for lightning-fast performance and smooth scrolling animations.

## 🚀 Getting Started

If you want to run or view this project locally:

```bash
# Install dependencies
npm install

# Start the dev server
npm run dev

# Build for production
npm run build
```
